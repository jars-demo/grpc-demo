All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- `grpcdemo.v1` Protocol Buffers contract: `WorkshopService` (unary `SayHello`, `ListTopics`, `GetTopic`; server-streaming `WatchEvents`; client-streaming `RecordMeasurements`; bidirectional `Chat`) and the mTLS-only `AdminService.GetServerStats`, with bindings generated by `scripts/generate_proto.py` and a `--check` mode for CI.
- Python gRPC server with plaintext (loopback only, off by default), TLS and mutual TLS listeners on one process, per-identity authorization, call statistics, the standard health service, message size limits, deadline/cancellation awareness and graceful shutdown.
- FastAPI REST API with the equivalent unary operations, strict request validation, consistent error bodies and a request body size limit; served over HTTP and HTTPS.
- Command-line gRPC client with a subcommand per RPC, connection profiles, and explanations of gRPC status codes and TLS failure details.
- Certificate lab (`certs/scripts/certs.py`) driving OpenSSL: a local educational CA, a rogue CA, server, expired-server, client, admin and rogue-client certificates; `list`, `inspect`, `verify`, `rotate`, `regenerate`, `clean`.
- Examples: wire tap with HTTP/2 frame decoding, TLS inspector, protobuf/JSON wire format, multiplexing, contract mismatch, REST client, latency comparison with connection-reuse mode.
- Final challenge: six real misconfigured connection profiles, runner, progressive hints and a checker that rejects insecure fixes.
- Fourteen workshop chapters (about 3¾ hours) from HTTP to mutual TLS and troubleshooting.
- Docker Compose environment (gRPC server, expired-certificate server, REST over HTTP and HTTPS, website, toolbox and challenge containers) with non-root, read-only, capability-dropped containers on loopback-only ports and real-path health checks.
- Next.js static website: landing page, chapter reader with progress tracking in local storage, reference docs, Mermaid diagrams from repository sources, light and dark themes.
- Tests: unit, gRPC behaviour, TLS/mTLS/authorization with real handshakes, certificate properties and rotation, challenge scenarios, repository hygiene, integration tests against the stack, website tests.
- CI (lint, types, generated-code consistency, tests, website build, full stack with smoke and integration tests) and a dependency-audit workflow.
